# Dependencies

Sental DSH Preflight uses these separately distributed projects:

| Project | Use | License |
| --- | --- | --- |
| [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) | The application launched from a user-selected installation | [MIT](https://github.com/deepseek-ai/deepseek-harness/blob/master/LICENSE) |
| [js-yaml](https://github.com/nodeca/js-yaml) | Read and write plugin configuration | MIT |
| [argparse](https://github.com/nodeca/argparse) | Transitive dependency of js-yaml | Python-2.0 |

The DSH source, its plugins, Node.js, and Microsoft components are not bundled in this repository. npm installs dependency license files with their packages.
